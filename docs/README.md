# 📝 Documentação do Projeto

Registro de decisões técnicas, especificações de ambiente, relatórios e artefatos de documentação do projeto.

## O que vai aqui

- **Decisões arquiteturais** — ADRs (Architecture Decision Records) explicando por que escolhemos X em vez de Y
- **Setup de ambiente** — guias de instalação, configuração de dependências, variáveis de ambiente
- **Especificações** — descrição detalhada de pipelines, schemas de dados, fluxos
- **Apresentações** — slides, atas de reunião, registros de decisão com o IPPUC

## Guias

- [Coletor de calçadas](coletor-de-calcadas.md): como usar o programa de coleta
  (`Calcadas.exe`), para quem não programa.

> Documentação é legado — o que vocês produzirem aqui vai beneficiar as próximas equipes e a cidade.
