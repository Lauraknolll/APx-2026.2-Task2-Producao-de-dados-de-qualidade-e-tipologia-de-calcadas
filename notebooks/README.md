# 📓 Jupyter Notebooks

Notebooks para análises exploratórias, prototipação e experimentação.

## Boas práticas

- **Nomenclatura**: `[numero]-[descricao-curta].ipynb` (ex: `01-analise-exploratoria-156.ipynb`)
- **Células**: mantenha o notebook limpo — execute em ordem antes de commitar
- **Saídas**: evite commitar outputs pesados (limpe antes do `git add`)
- **Código reutilizável**: migre funções maduras para `scripts/` ou `src/`

> Notebooks são ótimos para explorar, mas código final vai em /scripts.
